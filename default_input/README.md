# Комплектные данные

Эта папка предназначена для неизменяемого комплекта JSON. Автоматической генерации или сдвига дат нет.

Зерновые события за 2026-10-15 созданы один раз генератором `generator/create_fixed_demo_inputs.py`: 1 872 заявки и 936 сделок на 39 узлах, два максимума кривой около 18M и 30M. Полный состав событий, параметры и контрольная сумма находятся в `generation_info.json`. Календарь MOEX SPFI за 2026 год сохранён прежним.

В этой папке архив и портфель ГО отсутствуют: это прежний частичный пример `run_project.py --example`. Полная техническая демонстрация с архивом и портфелем находится отдельно в [examples/full_demo/](../examples/full_demo/README.md), запуск через `run_demo.py --serve`. Данные этой папки не заменены новым набором.

`--example` игнорирует пользовательский input и использует фиксированную дату из `run_settings.json`. Загрузка G-curve с MOEX всё равно происходит по HTTPS. Ошибки сети не подменяются локальным снимком.
