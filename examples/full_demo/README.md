# Полная техническая демонстрация

Из корня проекта после установки зависимостей:

```powershell
.venv/Scripts/python.exe run_demo.py --serve
```

Или двойной клик по `run_demo.bat`. Без `--serve` команда только сохраняет результаты и завершается. Используется основной расчётный путь `run_project.py`, без отдельной реализации финансовых формул.

Набор фиксирован на 2026-10-16: зерновые события, предыдущая кривая, портфель, 201 ежедневный снимок по 39 зерновым и процентным узлам и календарь MOEX SPFI. История из существующей технической фикстуры `tests.create_margin_test_input`, seed 123. Зерновой день создан существующим генератором с настройками `generator/parameters.json`, но датой 2026-10-16 и предыдущей датой 2026-10-15. В портфеле покупка 1000 т и встречная продажа 400 т. Входы скопированы из проверенного локального набора, не генерируются при запуске и не зависят от наличия tests/.

Пользовательский `input/` игнорируется. Риск-параметры остаются общими: 10000 сценариев, 99%, 5 торговых дней, минимум 200 изменений. Реальная G-curve на дату примера загружается по HTTPS MOEX; без сети или при недоступности даты соответствующий модуль сообщает ошибку, скрытого офлайн-fallback нет. Каждый запуск сохраняет отдельную папку output/.

Данные явно SYNTHETIC_TEST. Историческая форма не согласована с сегодняшней двухгорбой кривой. Замена последнего снимка рассчитанной кривой создаёт искусственный скачок, способный существенно увеличить ГО. Этот набор проверяет работу кода и интерфейса, но не рыночный уровень ГО, качество прогноза или обоснованность параметров. Стрессы и концентрационные надбавки отключены по общим настройкам.

Для рабочих данных запускай `run_project.py --serve`: он использует пользовательский input/, а не этот набор. Старый частичный пример `run_project.py --example` сохранён отдельно и по-прежнему не содержит архива ГО.
