# Фиксированный плотный пример

Генератор запускается только явно. Обычный `run_project.py` не импортирует и не вызывает его. Уже созданные JSON используются повторно без изменения дат и случайных чисел.

```powershell
.venv/Scripts/python.exe -m generator.create_fixed_demo_inputs --output-dir default_input
```

Если файлы существуют, команда отказывается их заменять. Для осознанной замены нужен `--replace-existing`; предыдущие файлы автоматически копируются в отдельную папку `output/default_input_backup_...`.

Настройки находятся в `generator/parameters.json`, отдельно от параметров финансовой считалки. Дата примера фиксирована: 2026-10-15. Seed: 42. Форма задана опорными точками 1D=20 000, 6M=20 500, 18M=21 800, 24M=21 200, 30M=22 200, 36M=21 500 руб./т. Между опорными точками используется log-linear по фактическим датам. Это конструкция демонстрационного рынка, не рыночная калибровка или экспертная цена.

Для каждого из 39 узлов создаются 6 внутридневных сессий, в каждой 4 уровня покупки и 4 уровня продажи. Итого 1 872 новые заявки, 936 сделок, 1 560 отмен, 936 исполнений и 936 восстановлений остатка через MODIFY. Одновременно активны 312 заявок. События выставления, исполнения, восстановления и замены согласованы по идентификаторам и остаткам. Новые сессии сначала снимают прежние котировки; последние заявки остаются до конца дня. Каждый из 160 срезов обеспечен глубиной с обеих сторон.

Объём сделок каждого узла равен 75% объёма полного веса из выбранных параметров считалки. Для действующих настроек это выше минимального дневного объёма. В итоговой цене участвуют и сделки, и заявки: все узлы MIXED, вес сделок 0.75. Исполнения чередуются по лучшим ценам покупки и продажи, их остатки сразу восстанавливаются отдельным событием MODIFY. Все сделки и заявки безадресные, заявки лимитные.

Небольшой общий внутридневной сдвиг центров котировок до ±0.02% не создаёт дополнительных локальных горбов по срокам. Предыдущая кривая равна опорной форме с коэффициентом 0.998. Итоговую сегодняшнюю кривую рассчитывает обычная финансовая считалка из событий, не генератор и не фронт. До сохранения проверяются 39 узлов MIXED, 160 допустимых срезов у каждого и два максимума на 18M/30M.

Количество событий и результаты проверки, настройки и SHA-256 входного файла сохраняются в `default_input/generation_info.json`. Набор предназначен для функциональной проверки плотного рынка. Он намеренно обеспечивает наблюдения на всех сроках и не отражает реальную ликвидность, сезонность, волатильность или частоту торгов зерном. Архив для GARCH и портфель данный генератор пока не создаёт.
